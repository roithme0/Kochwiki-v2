# Deferred Work

This directory records known work that has been consciously postponed. A deferred item documents why the work matters, why it is not being done now, and what observable outcome would close it.

Deferred items are not implementation approval. Before delivery, reassess the item against the current codebase and use the repository's spec workflow when the change needs product or architecture decisions.

Use [`template.md`](template.md) for new items. Remove an item when its work is delivered or no longer relevant; do not use this directory as a permanent backlog of unowned ideas.
